# L40 – Code Line Counter

**Student:** DHRUV LUHAR | **Roll:** H17 | **Division:** H | **Enrollment:** 24004501210161

## Problem
Analyse a project folder: files by type, lines of code and TODO comments.

## Who will use it
A team lead reviewing the size of a project.

## Folder structure
- `main.sh`: Menu-driven controller script
- `lib/functions.sh`: Function implementations for metrics, backup, and reports
- `data/project/`: Code directory containing 16 multi-language source files (.py, .js, .c, .sh)
- `reports/`: Text reports generated by feature 5 and the cron task
- `backups/`: Timestamped tar.gz archives of project data
- `logs/`: `activity.log` and `cron.log`

## Features
1. Count files by extension (`find`, `sed`, `sort`, `uniq -c`)
2. Lines per language (`find`, `wc -l`, `awk`)
3. 5 largest files (`wc -l`, `du -h`, `sort -nr | head -n 5`)
4. List TODO/FIXME comments (`grep -rnEI`)
5. Project stats report (summary saved to `reports/`)
